# Architecture Diagrams & Visual Artifacts

This directory contains raw diagram sources, vector assets, and exported architecture images for the **Azure Databricks Lakehouse Platform**.

## Folder Structure

- `drawio/`: Editable XML source files for Draw.io / Diagrams.net.
- `diagrams/`: Mermaid.js and PlantUML definition files.
- `exports/`: Production PNG, SVG, and PDF exports for documentation and GitHub README embedding.
